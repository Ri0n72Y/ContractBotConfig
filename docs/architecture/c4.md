# Contract Skill Pack MVP — 业务主链图

当前 MVP 的共同模式：Harness 加载 ContractBot Skills；需要资料库时通过固定内网 IP 的 OpenContracts MCP；正式入库时客户端不持有 WorkerKey，由服务器端 Caddy 注入。

## 1. 本地分析 / 起草 / 修改

```mermaid
flowchart TB
    U[用户] --> H[WorkBuddy / Harness]
    H --> S[contract]
    S --> F[本地合同 / 标书 / 用户资料]
    F --> P[分析 / 起草 / 修改]
    P --> D[contract-document]
    D --> H
    H <--> L[LLM]
    H --> O[回答 / 合同文件]
```

这条链不需要 OpenContracts，当前文件默认留在 Harness 本地。

## 2. 历史合同 / 模板检索

固定 Corpus：

```text
contracts-history
contract-templates
```

```mermaid
flowchart TB
    U[用户] --> H[Harness]
    H --> S1[contract]
    S1 --> S2[contract-repository]
    S2 --> C[Caddy :80]
    C --> M[OpenContracts MCP /mcp/]
    M --> CH[contracts-history]
    M --> CT[contract-templates]
    CH --> R[Reference Pack]
    CT --> R
    R --> H
    H <--> L[LLM]
    H --> O[回答 / 文件]
```

客户端 MCP URL 由分发包中的 `.mcp.json` 提供，例如：

```text
http://<fixed-lan-ip>/mcp/
```

## 3A. 正式入库前检查

```mermaid
flowchart TB
    U[用户明确要求入库] --> H[Harness]
    H --> S[contract-upload]
    S --> A[确认授权和目标文件]
    A --> R[contract-repository]
    R --> M[OpenContracts MCP]
    M --> CH[contracts-history]
    CH --> D[重复判断]
    D --> H
```

正式入库与分析、修改、文件生成相互独立，必须有用户明确授权。

## 3B. 正式入库写入链

```mermaid
flowchart TB
    H[Harness] --> S[contract-upload]
    S --> P[Multipart POST\n无 Authorization]
    P --> C[Caddy :80]
    C --> W[服务器端注入 WorkerKey]
    W --> A[OpenContracts Import API]
    A --> X[解析 / 索引]
    X --> CH[contracts-history]
    CH --> M[OpenContracts MCP]
    M --> V[后续核验]
    V --> H
```

关键边界：

```text
客户端
  无 WorkerKey
  无 add_to_corpus_id
  只发送文件和业务元数据

Caddy
  从服务器 .env 获得 WorkerKey
  覆盖 Authorization header

OpenContracts
  WorkerKey 绑定 contracts-history
```

因此正式写凭据不进入客户 ZIP、Skill、MCP 或用户环境。

## 4. 客户端安装

```mermaid
flowchart TB
    Z[ContractBot-Client.zip] --> H[兼容 Harness]
    H --> I[读取 INSTALL.md]
    I --> M[全局安装 .mcp.json]
    I --> S[全局安装 skills/]
    M --> R[重载 / 重启 Harness]
    S --> R
```

Windows fallback 是 `client-setup.ps1`，只负责 MCP 和 Skills，不安装证书、不写 WorkerKey、不创建 ContractBot runtime 目录。

## 5. 经验沉淀

```mermaid
flowchart TB
    H[Harness] --> S[contract-learning]
    S --> N[contract-experience-note.md]
    N -.人工审核.-> G[Git / Skill 更新]
    G -.发布.-> F[未来 Skill 版本]
```

经验材料不进入 OpenContracts，也不存在 learning Corpus。
