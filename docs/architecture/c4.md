# Contract Skill Pack MVP — 业务主链图

当前 MVP 的共同模式：Harness 加载 ContractBot Skills；需要资料库时通过固定内网 IP 的 OpenContracts MCP；正式入库时客户端不持有 WorkerKey，由服务器端 Caddy 注入。

## 1. 本地分析 / 起草 / 修改

```mermaid
flowchart TB
    U[用户] --> H[WorkBuddy / Harness]
    H --> S[contract]
    S --> F[本地合同 / 标书 / 用户资料]
    F --> P[分析 / 起草 / 修改]
    P --> D[contract-document]
    D --> H
    H <--> L[LLM]
    H --> O[回答 / 合同文件]
```

这条链不需要 OpenContracts，当前文件默认留在 Harness 本地。

## 2. 历史合同 / 模板检索

固定 Corpus：

```text
contracts-history
contract-templates
```

```mermaid
flowchart TB
    U[用户] --> H[Harness]
    H --> S1[contract]
    S1 --> S2[contract-repository]
    S2 --> C[Caddy :443]
    C --> M[OpenContracts MCP /mcp/]
    M --> CH[contracts-history]
    M --> CT[contract-templates]
    CH --> R[Reference Pack]
    CT --> R
    R --> H
    H <--> L[LLM]
    H --> O[回答 / 文件]
```

客户端 MCP URL 固定在分发包中的 `.mcp.json`：

```text
https://192.168.200.69/mcp/
```

## 3A. 正式入库前检查

```mermaid
flowchart TB
    U[用户明确要求入库] --> H[Harness]
    H --> S[contract-upload]
    S --> A[确认授权和目标文件]
    A --> R[contract-repository]
    R --> M[OpenContracts MCP]
    M --> CH[contracts-history]
    CH --> D[重复判断]
    D --> H
```

正式入库与分析、修改、文件生成相互独立，必须有用户明确授权。

## 3B. 正式入库写入链

```mermaid
flowchart TB
    H[Harness] --> S[contract-upload]
    S --> P[HTTPS Multipart POST\n无 Authorization]
    P --> C[Caddy :443]
    C --> W[服务器端注入 WorkerKey]
    W --> A[OpenContracts Import API]
    A --> X[解析 / 索引]
    X --> CH[contracts-history]
    CH --> M[OpenContracts MCP]
    M --> V[后续核验]
    V --> H
```

关键边界：

```text
客户端
  无 WorkerKey
  无 add_to_corpus_id
  只发送文件和业务元数据

Caddy
  从服务器 .env 获得 WorkerKey
  覆盖 Authorization header

OpenContracts
  WorkerKey 绑定 contracts-history
```

因此正式写凭据不进入客户 ZIP、Skill、MCP 或用户环境。

## 4. 客户端安装

```mermaid
flowchart TB
    Z[ContractBot-Client.zip] --> H[兼容 Harness]
    H --> I[读取 INSTALL.md]
    I --> CA[信任 bundled Caddy Root CA\n当前用户证书存储]
    CA --> M[全局安装 .mcp.json]
    CA --> S[全局安装 skills/]
    M --> R[重载 / 重启 Harness]
    S --> R
```

客户端包包含：

```text
.mcp.json
certificates/opencontracts-caddy-root.crt
skills/
INSTALL.md
README.md
```

其中 root CA 证书是公开信任材料；CA 私钥和 WorkerKey 始终只存在服务器侧。客户端包不包含 setup 脚本、helper runtime 或 ContractBot 环境变量。
