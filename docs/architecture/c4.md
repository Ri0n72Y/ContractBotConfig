# Contract Skill Pack MVP — 业务主链图

此前的 Mermaid C4 DSL 在部分渲染器中不受支持。这里改用基础 `flowchart`，按业务主链拆成小图。

资源实体统一显式标注：

- `SKILL:` — 可加载的 Skill 资源；
- `MCP:` — OpenContracts MCP 资源；
- `CORPUS:` — OpenContracts Corpus 资源。

其他节点只表示普通运行步骤、基础设施或人工流程。

## 1. 本地合同处理主链

```mermaid
flowchart LR
    U[用户] --> H[WorkBuddy / Harness]
    H --> S["SKILL: contract"]
    S --> D["SKILL: contract-document"]
    D --> F[本地合同 / DOCX / Artifact]

    classDef skill fill:#fff3cd,stroke:#9a6700,stroke-width:2px;
    class S,D skill;
```

这条链不依赖 OpenContracts。当前文件、分析、修改、起草和正式文档生成默认都留在 Harness 本地。

## 2. 历史合同 / 模板检索主链

```mermaid
flowchart LR
    S["SKILL: contract"] --> R["SKILL: contract-repository"]
    R --> H[Harness MCP Client]
    H --> C[Caddy HTTPS :443]
    C --> M[["MCP: OpenContracts /mcp/"]]
    M --> HC[("CORPUS: contracts-history")]
    M --> TC[("CORPUS: contract-templates")]
    HC --> P[Reference Pack]
    TC --> P
    P --> S

    classDef skill fill:#fff3cd,stroke:#9a6700,stroke-width:2px;
    classDef mcp fill:#dbeafe,stroke:#1d4ed8,stroke-width:2px;
    classDef corpus fill:#dcfce7,stroke:#15803d,stroke-width:2px;
    class S,R skill;
    class M mcp;
    class HC,TC corpus;
```

这里真正的远程业务资源只有一个 MCP 和两个 Corpus。Caddy、MCP Client、Reference Pack 都只是访问或处理中间环节。

## 3. 正式合同入库主链

```mermaid
flowchart LR
    U[用户明确授权入库] --> S["SKILL: contract-upload"]
    S --> Q[通过 MCP 做重复检查]
    Q --> H[upload_document.py]
    H --> C[Caddy HTTPS :443]
    C --> A[OpenContracts Import API]
    A --> P[解析 / 索引]
    P --> HC[("CORPUS: contracts-history")]
    HC --> M[["MCP: OpenContracts /mcp/"]]
    M --> V[后续核验可读 / 可检索状态]

    classDef skill fill:#fff3cd,stroke:#9a6700,stroke-width:2px;
    classDef mcp fill:#dbeafe,stroke:#1d4ed8,stroke-width:2px;
    classDef corpus fill:#dcfce7,stroke:#15803d,stroke-width:2px;
    class S skill;
    class M mcp;
    class HC corpus;
```

正式写入只进入 `contracts-history`。`OPENCONTRACTS_UPLOAD_WORKER_KEY` 绑定这个 Corpus，上传 helper 不允许调用方另选目标 Corpus。

## 4. 经验沉淀 / Skill 更新主链

```mermaid
flowchart LR
    S["SKILL: contract"] --> L["SKILL: contract-learning"]
    L --> N[本地 contract-experience-note.md]
    N --> R[维护人员人工收集 / 审核 / 合并]
    R --> G[Git 修改 Skill]
    G --> P[发布新版本 Skill Pack]
    P --> S2["SKILL: contract / repository / document 等"]

    classDef skill fill:#fff3cd,stroke:#9a6700,stroke-width:2px;
    class S,L,S2 skill;
```

这条链完全不经过 MCP 或 Corpus。经验只有经过人工审核并修改 Git 中的 Skill 后，才会影响后续运行行为。
