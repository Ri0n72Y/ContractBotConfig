# Client runtime configuration

This directory belongs to the distributable client bundle.

`opencontracts.env.example` documents the runtime variables installed on the client. `workbuddy.settings.example.json` documents the intended reduced MCP tool surface for compatible Harnesses.

`contractbot-client.json` is generated by the server-side preparation script and contains the formal-ingestion WorkerKey. It is ignored by Git, must never be committed, and should be deleted from an extracted client bundle after installation.
